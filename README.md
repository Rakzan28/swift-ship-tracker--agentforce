# Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce

This project is a Salesforce Agentforce-based solution for analyzing customer support tickets, predicting ticket priority, and supporting automated assignment.

## Project Overview

The system uses Salesforce and Agentforce to analyze support ticket information and assist in identifying ticket priority. It is designed to improve ticket handling, prioritization, and assignment of customer support requests.

## Technologies Used

- Salesforce
- Agentforce
- Salesforce Flow
- Salesforce Custom Objects
- Salesforce Permission Sets
- Salesforce CLI
- Git
- GitHub

## Main Components

- Support Ticket Intelligence custom object
- Support Ticket Intelligence automation Flow
- Support Ticket Priority Analysis permission set
- Agentforce-based ticket priority analysis

## Project Purpose

The main objective is to automate and improve the customer support ticket prioritization process using Salesforce Agentforce.
